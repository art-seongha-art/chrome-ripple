# WORK 31 — 파문 (Chrome Ripple)

어두운 전시장 바닥에 놓인 2m 스테인레스 덩어리. 윗면은 얼어붙은 물결이고, 모서리로 선
거울 큐브가 그 수면에 잠겨 있다. 웹캠 앞에서 손을 움직이면 금속이 눌리고 파문이 퍼진다.

- 치수: 2000 × 800 × 500 mm (도면 그대로 미터 단위로 모델링)
- 실행: `index.html` 하나. CDN 의존 없음 (three.js r185 로컬 번들)

## 인터넷에서 바로 보기

**https://art-seongha-art.github.io/chrome-ripple/**

GitHub Pages는 HTTPS라 웹캠이 그대로 작동한다. 접속 후 화면을 누르고 카메라를 허용하면 된다.

## 내 컴퓨터에서 실행

웹캠은 보안 컨텍스트에서만 열린다. 파일을 더블클릭하면(`file://`) 손짓이 꺼진 채로 뜬다.

```bash
cd works/31_chrome-ripple && python3 -m http.server 8031
```

그 뒤 `http://localhost:8031` 로 접속. 웹캠을 거부해도 마우스와 무인 연주로 계속 작동한다.

## 조작

| 입력 | 동작 |
|------|------|
| 드래그 | 수면 직접 건드리기 (누른 자리에 파문) |
| 우클릭 드래그 | 카메라 회전 (자동 카메라 해제됨) |
| 휠 | 다가가기 |
| **C** | 자동 카메라 켜기/끄기 · **Space** 다음 샷 |
| **H** | 화면 정리 · **F** 전체화면 · **R** 수면 재우기 |

## 구조

| 층 | 무엇 |
|---|---|
| 파동 | GPU 파동방정식 `h' = 2h − h_prev + ∇²h·c²`, 512×205 부동소수 텍스처 두 장 핑퐁 |
| 힘의 장 | 160×64. 웹캠 손짓 + 포인터 + 큐브 접점 + 무인 연주가 한 장에 합쳐짐 |
| 수면 | 얼어붙은 물결(8성분 방향파) + 파동 시뮬 + 잔물결. 법선은 픽셀에서 계산 |
| 둘레 띠 | 상판 가장자리를 도는 띠. 윗줄만 수면과 함께 움직여 실루엣이 울퉁불퉁해진다 |
| 환경 | HDRI(Poly Haven CC0) 안에 조명 띠를 세워 PMREM으로 함께 구움 |
| 후처리 | 블룸 → 톤매핑 → 비네트·그레인·색수차 |

## 만들면서 걸렸던 것 — 다시 밟지 않기 위해

1. **지속적인 힘을 높이에 더하면 발산한다.** 파동방정식에 상수 힘 `F`를 매 스텝 더하면
   평형 높이가 `F/(1−감쇠)` — 감쇠 0.997이면 300배가 된다. 손이 한 자리에 머무는 순간
   수면이 폭발했다. 지금은 더하지 않고 **목표 깊이로 끌어당긴다**(`mix(h, −깊이, 붙잡음)`).
   눌리는 깊이에 상한이 생기고, 손을 떼면 튀어오르며 파문이 된다.

2. **힘의 장은 누적이 아니라 최대값이다.** `+=` 로 쌓으면 감쇠와 곱해져 사람이 조절할 수
   없는 값이 된다. `max` 로 두면 "지금 여기가 얼마나 눌려 있나"가 그대로 0~1이 된다.

3. **거울면은 광원의 밝기가 아니라 개수와 가늘기가 인상을 정한다.** 넓은 광원 하나는
   물결이 아무리 쳐도 흰 판 하나로 뭉갠다. 가는 띠 여럿이라야 사진처럼 잘게 찢어진다.

4. **방이 완전한 검정이면 금속은 점만 튀는 검은 덩어리가 된다.** 중간톤이 통째로 비쳐야
   형태가 읽힌다. 반짝임을 줄이는 길은 밝기를 낮추는 게 아니라 중간톤을 넣는 것이다.

5. **HDRI는 파일마다 노출이 제각각이다.** 폐공장은 창이 타고 밤은 새까맣다. 불러온 뒤
   평균 밝기를 재서 같은 값으로 맞추고, 밝은 쪽만 부드러운 무릎으로 눌러 굽는다
   (`normalizeHDR`). 이걸 안 하면 환경을 바꿀 때마다 노출을 다시 잡아야 한다.

6. **잔주름이 픽셀보다 작아지면 반짝임 앨리어싱이 된다.** 노출로는 안 잡힌다.
   화면에서 법선이 빨리 변하는 곳(`fwidth(normal)`)일수록 거칠기를 올리는
   스페큘러 안티앨리어싱으로 해결했다.

7. **r185의 `RGBELoader`는 268바이트짜리 껍데기**이고 실체는 `HDRLoader.js`다. 이름만 보고
   복사하면 404가 나고, ES 모듈은 하나라도 404면 **그래프 전체가 죽어 아무것도 실행되지
   않는다.** 콘솔에 오류도 안 남으니 이럴 땐 네트워크 요청 목록을 봐야 한다.

8. **프레임 루프에서 예외가 나면 그 프레임은 안 그려지고 캔버스는 지워진 채 남아
   '검은 깜빡임'이 된다.** 그래서 루프 본문을 감싸 예외로 빠져나가지 않게 했다.
   같은 증상은 GPU가 밀려 프레임을 건너뛸 때도 나므로, 면 분할과 픽셀 비율을 낮추고
   느려지면 두 단계로 자동 강등한다.

## 손짓의 성격을 바꾸고 싶다면

`motionToForce(motion, presence)` 하나만 갈아끼우면 작품의 성격이 바뀐다.

- 지금(자석 같은 손): 움직임 + 머무름 → 손을 든 채 멈춰도 눌린 자국이 남고 서서히 풀린다
- 움직임의 시작에만 한 번 때리기 → 물방울처럼 똑똑 떨어지는 성격
- 손이 간 방향으로 밀기 → 배가 지나간 자국처럼 끌리는 성격
